Start

Perioder följer datorns lokala kalender. Ett pass räknas till datumet då det började. Tid och distans gäller den del bryggan faktiskt loggat; saknade mätvärden räknas inte som noll. Kalorier från PM5 loggas från anslutningen och äldre pass kan sakna kaloridata. Inga uppskattade kalorier blandas med uppmätta värden.

Historiken finns lokalt i $XDG_DATA_HOME/bikeerg/workouts.sqlite3 (normalt ~/.local/share/bikeerg/workouts.sqlite3). Demo i spelet skapar inga träningspass.
