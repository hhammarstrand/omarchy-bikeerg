Start

Pass loggas medan bryggan är igång. Efter 90 sekunder utan trampning eller färsk anslutning avslutas passet. PM5:s återställda passklocka startar ett nytt pass. Tid räknas bara medan färsk data kommer in, inklusive korta pauser; distansen beräknas från hastigheten. Historiken kan därför skilja sig från PM5:s totalsiffror om anslutningen startar mitt i ett pass eller avbryts.

Lagring: $XDG_DATA_HOME/bikeerg/workouts.sqlite3 (normalt ~/.local/share/bikeerg/workouts.sqlite3). Ingen uppladdning eller molnsynk. Demo i spelet skapar inga träningspass.
